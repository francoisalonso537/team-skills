# François Team Skills

Reusable desktop assistant workflows with private setup for each person.

## Start

Open a desktop Work/Codex chat with local file access. Paste the repository link and ask:

> Install Expense Claim Assistant from https://github.com/francoisalonso537/team-skills. Read INSTALL.md and handle the setup for me. Preserve my existing settings, verify installation, then help me configure my receipts and company Excel template. Leave all Teams approvals unsent for my review.

You may need to approve an installation prompt or restart the app. A normal web/mobile chat cannot install these local files.

## Expense Claim Assistant

Prepares an Excel expense claim and numbered receipt PDF. Checks Outlook and Google Calendar through Chrome when available and leaves unsupported descriptions blank. Uses your own prior Teams claims to prepare an unsent approval when Teams access is available. Your receipts, templates, accounts, and personal configuration are not included.

Only generic workflow files belong in this public repository. Never add claims, receipts, personal configuration, access tokens, or company templates.
